# Portfolio de Eduardo Ladeira

Site pessoal com projetos de Business Intelligence, dashboards e consultas SQL. Inclui apresentação em português e inglês, galeria de projetos e visualização do currículo.

## Tecnologias

Next.js, React, TypeScript e Tailwind CSS. O deploy é feito na Vercel a partir da branch `main`.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000). Para conferir a versão de produção localmente, use `npm run build` e `npm run start`.

## Estrutura

- `app/page.tsx`: conteúdo e seções da página.
- `components/`: navegação, galeria, idioma e currículo.
- `public/`: imagens, ícones e arquivos dos currículos.
